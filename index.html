🎯 场景推荐

🏆 最佳综合旅行卡 — Amex Platinum (£650)

如果你年旅行3次以上且消费能力强：无限贵宾厅 + 全球旅行险 + FHR酒店升房 + £400餐饮返现。金属卡身份象征。£650年费看似高，但用足餐饮返现和旅行险后实际成本大幅降低。

💰 最佳性价比入门 — Amex Gold (£195, 首年£0)

首年免费 + 4次贵宾厅 + 3x旅行消费回馈 + Deliveroo £120/年。如果不确定自己是否高频旅行，从这张开始，一年后决定是否升级。

🛂 最便宜贵宾厅+0%FX组合 — Lloyds/Halifax World Elite (£180)

£180/年 = 2人无限次 Priority Pass + 全球0% FX。单独买 Priority Pass 要 £838/年。再加上 0% FX 和机场餐厅£18，简直是旅行最佳伴侣。不送积分但现金回报扎实。

✈️ BA常旅客 — BA Premium Plus (£300) 或 Barclaycard Avios Plus (£240)

前者：全舱位同行券（含商务舱），3x BA消费，限时Tier Points活动。后者：£10k低门槛升舱券，1.5x Avios全消费，Mastercard接受度更高。如果BA是主力航司，两者搭配使用效果最佳。

🆓 零年费最佳 — Barclaycard Avios (免费) 或 Virgin Reward (免费)

都不收年费。Barclaycard Avios 开卡礼低门槛（£1k得5k Avios）+ £20k升舱券。Virgin Reward EEA内0% FX。根据你偏好BA还是Virgin选择。

🔄 进阶玩法：Amex Platinum + Lloyds World Elite 双持

Platinum 覆盖贵宾厅、保险、酒店、餐饮；Lloyds World Elite 填上 0% FX 和机场餐厅的空缺。如果再加上 Curve 来 Back in Time 和反尴尬模式，基本覆盖所有旅行场景。
